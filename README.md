# quantlab-public-cards

Public result cards for @quantlabHQ on X, published via Buffer.

QuantLab Beta trade results auto-post to X through Buffer, and Buffer requires
a stable public URL for the attached image (it stores the URL as-is and does
not re-host). This repo holds those cards so the link does not rot the way
anonymous upload hosts (uguu.se, litterbox) do.

Cards are results only: R multiple, dollar P&L, running record, month totals.
No entries, exits, direction, price levels, or timing ever land here (see
qlb-public-secrecy in Ryan's memory). Written by `~/quantlabbeta/bin/qlb_x_post.py`.
